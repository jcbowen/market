# 登录页重设计 Todolist（2026-10-16）

## 需求背景

现登录页（http://localhost:18080/b/#/login）为灰底 + 白卡片的最简样式，观感简陋。重设计为有品牌感、现代感的登录页。

## 方案要点

- 桌面端（≥900px）：左侧品牌区（品牌绿 #07c160 渐变 + Logo + slogan + 产品特性 + 纯 CSS 装饰），右侧登录表单区（欢迎语、图标输入框、品牌绿按钮、版权）
- 窄屏（<900px）：品牌区收起，顶部绿色渐变头部 + 单栏表单
- 登录逻辑零改动：表单校验、onLogin、redirect 回跳保持原样，只动模板结构与样式
- 不引入图片资源，装饰全部纯 CSS；图标用项目已有 @vicons/ionicons5

## 任务清单

- [x] 1. 重写 src/admin/src/views/login/index.vue 模板与样式，登录逻辑/校验/回跳逻辑不变
- [x] 2. 品牌区：Logo 徽标 + 系统名 + slogan + 产品特性列表 + 纯 CSS 装饰（圆环/光点）
- [x] 3. 表单区：欢迎语、前缀图标输入框、加载态登录按钮、底部版权
- [x] 4. 响应式适配：<900px 单栏布局，小屏不破版
- [x] 5. 浏览器验证（dev server http://localhost:3001/b/#/login）：窄屏单栏形态实测通过（677px 视口，无横向滚动条）、响应式规则编译生效、空表单校验提示正常、新版元素完整性确认
- [x] 6. 检查 docs：登录页仅有路由层描述，无 UI 视觉描述，无需同步更新
