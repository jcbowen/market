## 八、前端路由设计

### 8.1 C端（uni-app）页面路由

| 路径 | 页面名称 | 说明 | TabBar |
|------|----------|------|--------|
| pages/index/index | 首页 | 社区商品、分类导航、Banner | 是 |
| pages/category/category | 分类 | 商品分类浏览、商品搜索 | 是 |
| pages/cart/cart | 购物车 | 购物车列表 | 是 |
| pages/user/user | 我的 | 个人中心 | 是 |
| pages/product/detail | 商品详情 | 多规格选择、加入购物车 | 否 |
| pages/order/list | 订单列表 | 按状态 Tab 切换 | 否 |
| pages/order/detail | 订单详情 | 物流/状态跟踪、申请退款 | 否 |
| pages/order/confirm | 确认订单 | 选择地址、优惠券、提交 | 否 |
| pages/address/list | 地址管理 | 地址列表 | 否 |
| pages/address/edit | 编辑地址 | 新增/修改地址 | 否 |
| pages/community/select | 选择社区 | LBS 定位、社区列表 | 否 |
| pages/coupon/coupon | 优惠券 | 领取中心/我的优惠券（Tab 切换） | 否 |
| pages/flash/flash | 秒杀活动 | 秒杀商品列表 | 否 |
| pages/full-reduction/full-reduction | 满减活动 | 满减活动列表 | 否 |
| pages/login/login | 登录 | 微信/支付宝/手机号登录 | 否 |

> 说明：商品搜索能力已内嵌在分类页顶部搜索栏，不单独提供 `pages/product/search`；退款申请已内嵌在订单详情页和订单列表中，不单独提供 `pages/order/refund`。
