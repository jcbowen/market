### 8.1.1 通用跳转封装（goPage）

C 端统一通过 `src/client/src/utils/navigate.ts` 的 `goPage(url)` 执行页面跳转，自动处理跳转方式选择：

| 场景 | 处理方式 |
|------|----------|
| tabBar 页面（分类/购物车/我的） | `uni.switchTab`（不支持 query 参数，参数自动丢弃，带参数跳转时控制台输出警告） |
| 普通页面 | `uni.navigateTo`，失败（如页面栈超 10 层）降级 `uni.redirectTo` |
| 外部链接（http/https 开头） | H5 端 `window.open` 新窗口；小程序/APP 端提示暂不支持 |

- tabBar 页面路径列表由脚本 `src/client/scripts/gen-tab-bar-paths.js` 从 `pages.json` 的 `tabBar.list` 自动生成到 `src/utils/tab-bar-paths.ts`（生成文件提交 git 跟踪，内容无变化不落盘）；dev/build 命令已前置自动执行，修改 `pages.json` 后重启 dev 或重新 build 即可同步。
- `utils/navigate.ts` 除 `goPage` 外还导出 `goLogin`（带 redirect 回跳）、`goBack`（无上一页时回首页）、`goHome`（跳 `pages/category/category`）、`goProductDetail`、`goOrderConfirm`、`goOrderList`、`goOrderDetail`、`goAddressList`、`goAddressEdit`、`goCommunitySelect`、`goCoupon`、`goFlash`、`goFullReduction`；履约工作台无专用封装，由「我的」页面直接 `uni.navigateTo`。
- 后台管理端 Banner 链接选择器（`src/admin/src/components/LinkSelector.vue`）生成的内部跳转地址与本封装的解析规则一致：页面/活动为 `/pages/xxx/xxx`，商品为 `/pages/product/detail?id=N`。
