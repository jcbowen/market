**列表页路由 query 预筛选约定（工作台待办直达，2026-10-17）：**

- `/orders?status=N`：订单列表按 N 预筛选，N 仅接受本页状态筛选项支持的值（1 待支付、90 待发货聚合、4 配送中、5 已完成、6 已取消、9 售后聚合）；无参数或非法值回落「全部订单」
- `/refunds?status=N`：售后列表按 N 预筛选，N 仅接受退款单状态 1~5（待审核/已同意/已拒绝/退款中/已退款）；无参数或非法值回落「全部」
- 两页均注册 keep-alive，`onActivated` 时重新应用 query：从工作台待办重复进入会按最新参数刷新列表，而非停留在首次筛选状态
- 工作台待办中心入口即按上述参数跳转：待支付→`/orders?status=1`、待发货→`/orders?status=90`、待收货→`/orders?status=4`、售后待审核→`/refunds?status=1`、退款中→`/refunds?status=4`、库存预警→`/stock/warnings`

**Banner 管理双语境说明：**
- 营销管理 → Banner管理：社区业务语境，管理当前社区 banner；全局 banner（community_id=0）一并列表展示，带「全平台通用」标识且只读（修改入口在系统管理页）
- 系统管理 → 全局 Banner：超管专属语境，仅管理全平台通用 banner（community_id=0，适用社区锁定"全平台通用"），复用同一 BannerManager 组件按 scope 参数区分行为

**权限守卫行为（`router.beforeEach`）：**
- 未登录访问受保护页：重定向 `/login`（携带 `redirect` 原始地址）
- 已登录访问 `/login`：回兜底首页 `resolveHomePath()`（有 `dashboard:view` 进 `/dashboard`，否则按路径长度与字母序取第一个有权限的可见页；无可用页面时落 `/dashboard` 交由权限判定送至 `/403`）
- 刷新后处于 restoring 状态：`ensureReady()` 幂等恢复，失败（token 失效）自动登出并去 `/login`
- 多社区账号未选定社区：强制进入 `/select-community`（携带 `redirect`）；已选定后再次访问该页仅 `force=1` 放行，其余回兜底首页
- 非超管访问 `meta.space = 'system'` 路由：重定向兜底首页，无可用页面时去 `/403`
- 已登录但对目标路由无权限：保留登录态重定向 `/403`（展示被拦截路径，可返回首页或重新登录），不再强制登出
- 仅当登录账号无任何可用页面（权限列表为空）时才登出兜底
- 收银台应用（`/pos` 前缀）：独立登录页与鉴权，未登录一律去 `/pos/login`；已登录访问 `/pos/login` 直接进 `/pos/cashier`；多社区账号未选定社区先去 `/select-community`；权限不足跳主系统 `/403`（要求 `order:create`）
