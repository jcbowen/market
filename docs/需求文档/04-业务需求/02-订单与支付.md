
```
待支付 → 已支付 → 已发货(自提) / 配送中(送货上门) → 已完成
  ↓                    ↓
取消              退款申请 → 已退款
```

- 一笔订单支持多次支付（例如首次支付失败后重新支付、组合支付等），每次支付生成独立支付单。
- 一笔支付单支持多次部分退款，退款金额累计不超过对应支付单金额。
- 退款申请审核通过后，先调用第三方支付退款，成功后再更新订单状态为已退款并释放库存。

### 4.3 支付方式

| 方式 | 场景 | 说明 |
|---|---|---|
| 微信支付 | 微信小程序、H5 | 当 `wechat` 支付 V3 配置不完整时，C 端不展示微信支付选项 |
| 支付宝支付 | 支付宝小程序、H5 | 当前保持关闭状态，仅做配置保存 |
| 现金 | 线下收款，后台标记已支付 | 货到付款/现金支付直接同步订单状态，不经过第三方支付 |
