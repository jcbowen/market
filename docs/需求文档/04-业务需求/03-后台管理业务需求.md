### 4.4 后台管理端

#### 商品管理
- 商品分类管理（多级分类）
- 商品 CRUD
- 商品上下架
- 多规格/SKU 管理（SKU 规格图片支持后台上传，C 端选中规格时展示对应图片）
- SKU 划线价（`original_price`，原价，0 表示不展示）：单规格与多规格 SKU 行均可录入，随商品创建/更新的 `sku_items` 全量提交（网关 `toProtoSkuItems` 透传至 product 服务）
- 商品划线价汇总：保存 SKU 时以最低价 SKU 的划线价回写商品 `min_original_price`，与列表起售价（`min_price`）取同一 SKU，C 端详情/列表按该汇总值展示划线价

#### 库存管理
- **商品入库**：采购入库、退货入库，记录入库时间、保质期、批次号
- **商品出库**：销售出库（关联订单）、报损出库（过期/损坏）
- **库存盘点**：定期/不定期盘点，记录盘点差异，生成盘点单
- **库存预警**：低库存预警（低于安全库存）、保质期临期预警
- **库存流水**：所有库存变动记录，可追溯查询
- **一键生成补货单**：根据库存预警自动生成补货建议

#### 保质期管理
- 入库时录入生产日期 + 保质天数，自动计算过期日期
- 支持手动录入过期日期
- 临期预警提醒（可配置提前天数）

#### 订单管理
- 订单列表（状态/订单号/收货人姓名电话/下单时间范围/**来源**筛选；状态口径与后端聚合一致：待发货=已支付∪备货中，售后=退款中∪已退款；来源列 + 经手人列，详情展示来源与经手人）
- 状态概览卡片（点击即筛选对应状态）
- 订单详情（含物流信息展示与按状态渲染的操作按钮）
- **售后记录区块**：逐条展示本单每次退款（退款单类型「整单退/部分退/金额退」标签、退款金额并标注含运费金额、退款商品明细「商品名(规格)×数量」，仅金额退显示「不退商品」、退款单状态标签、退款原因/退款时间），无售后记录时区块不渲染；与售后管理页同源数据
- 订单列表/详情展示支付方式（pay_type：微信/支付宝/货到付款/现金）
- 发货操作（仅配送单；物流公司/单号必填，写入独立字段）
- 自提核销（自提单已支付后直接「核销完成」，无需发货）
- 取消订单（取消原因必填，取消后逐行回补库存并回补订单占用的优惠券）：后台列表/详情的取消入口与服务端口径一致——待支付单（任意支付方式）+ 货到付款未发货单（2 已支付/3 备货中）；配送中及之后走退款流程；门店单后台路径不做额外限制（只读控制仅在 C 端）
- 批量发货（选中配送单共用同一物流信息）与批量核销；订单 CSV 导出（含来源/经手人列）
- 退款审核处理（C 端申请单：同意/拒绝；退款中卡单支持「重试退款」；审批动作落 refund_logs 日志）
- 代客退款（后台/收银台发起，**免审核**：创建即置退款中并调用渠道退款，成功后统一收尾）：三种方式——整单退、部分商品退（勾选商品行与数量）、仅金额退（不退商品、不回补库存），金额默认服务端按实付汇算、可调低，整单退按运费策略决定是否退还运费；详见《订单与支付》4.2.2

#### 收银台（独立应用 /pos，代客下单，决策点⑥⑨）
- 入口：应用中心 → 收银台（独立登录页与布局壳，不套后台框架）；订单管理 → 收银台保留旧入口
- 选顾客：复用会员选择器（单选），可选「散客」（user_id=0）；选会员后自动带出其名下未使用券供代选
- 现场注册会员：会员选择器开启 `registerable` + `register-scene="pos"`，「新增会员」输入手机号（必填）与昵称（选填，缺省「会员+尾号4位」）即可注册；后端幂等——手机号已注册时复用既有会员并自动关联当前社区（提示「该手机号已是会员，已自动关联本社区」），新注册提示成功；注册成功后单选模式直接选中回传，`is_new` 供后续新用户活动扩展
- 选商品：按名称搜索在售商品，单规格点击即加入小票，多规格弹窗选规格；数量步进/删除行
- 配送方式：自提 / 配送 / 到店（到店仅收银台可用，即买即走）；配送单需收银员直填联系人、电话与地址（收银台无地址簿）
- 现金当场结清：收银台现金通道（pay_type=4，与货到付款 3 区分），支付单创建即成功并同步订单状态；**实付为 0（全额优惠）自动结清**
- 优惠计算：优惠券（代选）+ 满减 + 满额免配送费均由服务端下单时计算，页面金额仅作参考
- 订单来源：固定 `source=2`（收银台），记录经手人 ID/姓名快照；与 C 端单统一存储，订单列表按来源筛选 + 收银台订单快捷视图（来源下拉选「收银台」）
- 挂单：顾客暂离时把当前工作区（会员 + 商品快照）暂存为挂单并清空收银台；挂单列表可恢复（回填后原挂单删除）或删除；挂单不生成订单、不占库存；按社区隔离，多收银员不丢单

#### 收银台交接班（班次体系）
- **开工**：无进行中班次时收银台显示开工引导页（「开始营业」）；后端强制校验——无进行中班次拒绝下单（网关 + order 服务双重校验），收银单写入 `orders.shift_id`
- **交班**：顶栏操作员下拉「交班」打开确认弹窗，展示班次信息与统计：收款/退款仅展示实际有数据的支付方式（按 现金/微信/支付宝/付款码预留 顺序排列，渠道未接入时不占位），含现金合计（收款-退款）；确认后班次置已结束，统计冻结为 JSON 快照
- **交班即登出**：交班成功后强制退出登录，落回收银台登录页（换人收银需重新登录）
- **交班记录**：入口在交班确认弹窗内（「历史交班记录」按钮），不再单设菜单；记录页含交班小票（可打印）
- 退款统计口径：退款单关联订单归属班次（订单在哪个班次创建，退款计入该班次），已同意/退款中/已退款均计钱；现金类（货到付款 3 / 收银台现金 4）退款不走第三方渠道，直接记录退款流水

#### 用户管理
- 会员列表按**当前社区语境**（请求头 `X-Community-Id`）过滤会员-社区关联（`user_communities`），即"本社区会员"视图；超管通过顶栏切换社区查看不同社区，没有跨社区"全部会员"视图
- 列表支持昵称/手机号关键字搜索、正常/拉黑状态筛选，展示归属社区与「履约」标记列
- 会员现场注册（后台会员管理与收银台共用同一幂等注册接口 `POST /admin/users`）：手机号已注册（含其他社区老会员）不报错，复用既有会员并自动补写当前社区关联；响应 `is_new` 区分「新注册」与「复用」，注册来源由 `scene` 标记（`admin` 后台 / `pos` 收银台，非白名单值按 admin 处理）
- 拉黑/恢复：拉黑后该会员 C 端登录与已登录请求（含 refresh_token 静默续期）均被拦截
- 履约人员配置（B 履约工作台）：会员操作列「设为履约/取消履约」（user:update 权限），标记挂在 `user_communities` 行上（关联行不存在时先补建再置标记）；履约人员可在 C 端履约工作台送货上门与核销自提订单

#### 订单管理（履约协同）
- 配送单状态 2/3（已支付/备货中）时提供两种发货路径：「发货」（传统物流，强制单号）与「指派」（社区自配送，选择本社区履约人员，C 端工作台执行开始配送/送达拍照，决策点②送达必须上传签收照片）
- 订单列表/详情展示配送员（履约人员姓名快照）与签收凭证图片

#### 营销管理
- 优惠券创建与发放（创建/发布状态机/停发；支持手动发放给指定会员——批量选择、逐人独立校验、留存经手人；领取/发放记录可按券/会员/状态/来源追溯）
- 满减活动配置
- 秒杀活动管理
- Banner 管理（图片支持点击上传；社区业务语境管理当前社区 banner，全局 banner 一并展示带「全平台通用」标识且只读）

#### 数据统计
- 订单统计
- 销售统计
- 商品销量排行
- 营收报表

#### 门店管理（社区级菜单组）
- 门店设置（`community:config`）：社区管理员自助维护本社区运营资料，可改白名单——联系电话、负责人、自提点地址、配送费/起送金额/配送范围、营业时间、社区外配送开关；仅展示不可改——社区名称、所在地区、详细地址、经纬度、负责人电话、营业状态
- 员工管理（`admin:view`）：当前社区的任职员工（随顶栏社区切换变化）；添加员工时 username 已存在则复用账号追加任职，否则新建账号；编辑资料 + 本社区多角色任职（全量覆盖）；移除仅删本社区任职，账号与其他社区任职保留
- 角色管理（`role:view`）：管理**当前社区**的私有角色；内置社区管理员角色（`community_admin`）在此页只读（其权限由超管在「社区权限」页维护）；普通管理员可勾选的权限点不超出自身当前社区权限，防越权放大

#### 系统管理（独立系统空间）
- 入口在右上角用户下拉，不在左侧业务菜单展示；路由 `meta.space='system'`，**仅超管可进入**（系统级权限点不对社区分配，社区管理员只见业务菜单），非超管直连 URL 由守卫回落到业务首页
- 社区/自提点管理（`community:view`，超管）：经纬度支持新窗口打开高德官方坐标拾取器选点，复制坐标后粘贴一键解析回填；高德拾取页有反嵌套限制，不做 iframe 嵌套，不对接高德 API
- 社区权限（`community:view` + superOnly，仅超管）：按社区设置**权限上限**（载体为该社区内置 `community_admin` 角色的权限集），保存后运行时权限解析与其取交集，立即对社区全员生效；系统级权限点（`community:*`、`region:*`、`settings:*`）不进入可分配列表并自动剔除；收紧上限时提示受影响的本社区私有角色；内置角色缺失的存量社区在首次保存时自动创建
- 账号管理（`admin:view` + superOnly，仅超管）：只管账号本身——列表/新增/停用启用/重置密码/超管标记；社区任职不在此维护（由各社区员工管理页按社区视角操作）
- 全局角色（`role:view` + superOnly，仅超管）：管理 `community_id=0` 的全局角色
- 行政区划（`region:view`/`region:update`）：省/市/区县三级树形管理（关键词、层级、状态筛选，命中自动展开祖先链），全量约 3400 条带内存 + localStorage 7 天缓存；「行政区划更新」任务走异步任务：拉取上游（镜像源，兜底民政部官方接口）→ 展示新增/变更差异 → 确认覆盖入库，覆盖后自动清缓存；地址前缀与地址编辑的区划代码依赖此数据
- 全局 Banner 配置（超管专属，仅管理 community_id=0 的全平台通用 banner，适用社区锁定"全平台通用"；与社区业务端 Banner 管理复用同一组件，按访问语境区分；社区语境下全局 banner 只读）
- 支付配置（`settings:view`/`settings:update`）：渠道开关与顺序、微信/支付宝参数、商户证书上传
- 售后配置（`settings:view`/`settings:update`）：整单退时的运费退还策略（always 始终退 / never 不退 / user_decide 由用户选择），保存即时生效、无需重启，作用于退款汇算；入口在系统空间「系统管理」菜单（仅超管）
- 附件配置（`settings:view`/`settings:update`）：存储模式（本地 / 阿里云 OSS，预留 COS），OSS 预签名 URL 直传 + MD5 秒传；本地附件迁移工具入口在此页（路由 hidden，不进菜单）

#### 权限与菜单渲染（与 RBAC 实现对齐，详见《权限与数据隔离》）
- 权限模型为**权限点级 RBAC**，不是固定三级角色：账号（`admin_users`，含 `is_super` 标记）与「社区任职」（`admin_communities`：管理员 × 社区 × 角色，可多社区多角色）分离，角色（`admin_roles`）按社区归属区分全局角色（`community_id=0`）与社区私有角色
- 权限点命名 `模块:动作`（如 `product:view`、`order:create`、`refund:update`、`community:config`），清单集中在 `src/admin/src/constants/permissions.ts` 按模块分组维护；`*` 为通配全量
- 前端路由守卫按 `meta.permission` 判定（无权限保留登录态跳 `/403`，权限为空才登出兜底），左侧菜单按权限点 + `superOnly` 过滤，页面内按钮再按 `hasPermission` 控制（如附件配置的 `settings:update`）
- 后端网关每条管理路由挂 `RequirePermission("xxx")` 中间件：非 `admin` 类型令牌直接拒绝；超管放行；其余按（管理员 × 当前社区）**实时**解析任职角色权限并集，再与该社区的权限上限取交集，命中所需权限点之一即通过
- 收银台独立应用（`/pos`）页面同样按 `order:create` 判定，未选定社区时先跳社区选择页

#### 附件上传
- 后台所有图片输入框（商品封面图、Banner 图片等）均提供「上传图片」按钮与缩略图预览（收在输入框内部右侧，宽度行为与普通输入框一致），同时保留手动输入 URL 能力
- 上传通道由附件配置自动分流：
  - 本地模式：multipart 上传至后端落盘，经 `/uploads/` 静态路径访问
  - OSS 模式：前端计算文件 MD5 → 获取预签名 URL → PUT 直传 OSS → confirm 确认；MD5 命中秒传时直接返回已有文件地址
- 图片地址存取规则：数据库只存相对路径，上传完成/手动输入后输入框回显完整 URL，提交时由后端剥离域名；页面展示时由后端按附件配置的访问域名拼回完整 URL（本地模式需在附件配置中填写「自定义访问域名」）
- 附件记录统一存于 attachment 表，用于秒传与追溯

#### 个人设置
- 入口在右上角头像下拉（个人设置 / 退出登录），不在左侧菜单展示
- 支持修改真实姓名、手机号与登录密码

#### 响应式布局
- 全后台适配笔记本及窄屏（≤768px 视口）：
  - 统计卡断点自适应（1024px 起 4 列）
  - 左右布局表单窄屏自动切换为标签置顶
  - 弹窗窄屏下限制为 94vw，避免固定宽度溢出
  - 侧边栏 <768px 自动折叠
