
#### 认证模块

**管理员登录请求：**
```json
{
  "username": "admin",
  "password": "123456"
}
```

```json
{
  "type": 1,
  "items": [
    {
      "sku_id": 1,
      "quantity": 50,
      "batch_no": "BATCH20260717",
      "production_date": "2026-07-15",
      "expire_date": "2026-07-25"

  ],

}
```

**库存流水查询：**
```
GET /api/v1/admin/inventory/entries?sku_id=1&type=0&start_date=2026-07-01&end_date=2026-07-17&page=1&page_size=20
```

**创建盘点单请求：**
```json
{
  "remark": "7月定期盘点"
}
```

**提交盘点请求：**
```json
{
  "items": [
    {"sku_id": 1, "actual_stock": 48}
```
