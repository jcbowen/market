## 六、接口设计

### 6.1 通用规范

- 基础路径：`/api/v1/`（C端）、`/api/v1/admin/`（后台管理）
- 请求头：`Content-Type: application/json`，`Authorization: Bearer <token>`
- 响应格式：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

- 分页请求：

```json
{
  "page": 1,
  "page_size": 20
}
```

- 分页响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [],
    "total": 100,
    "page": 1,
    "page_size": 20
  }
}
```
