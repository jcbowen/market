#### 支付模块

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | /api/v1/payments | 发起支付 | 是 |
| POST | /api/v1/payments/callback/wechat | 微信支付回调 | 否 |
| POST | /api/v1/payments/callback/alipay | 支付宝支付回调 | 否 |

**发起支付请求：**
```json
{
  "order_id": 1,
  "channel": "wechat"
}
```

`channel` 取值：`wechat`、`alipay`、`cash`（货到付款）。微信 openid 由网关从当前登录用户资料解析，**不接受前端传入**；手机号登录用户的 openid 为 `phone_<手机号>` 占位值，视为不可用，支付自动回落微信 H5 通道。

**发起支付响应（微信 JSAPI，用户有可用 openid）：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "payment_no": "ZF237681a6-cd0b-4c3d-a47f-2adc9f67614f",
    "pay_type": 1,
    "amount": 11.98,
    "wechat_pay_params": "{\"appId\":\"wx1234567890\",\"timeStamp\":\"1760000000\",\"nonceStr\":\"a1b2c3\",\"package\":\"prepay_id=wx202610091200\",\"signType\":\"RSA\",\"paySign\":\"BASE64SIGN\"}"
  }
}
```

**发起支付响应（微信 H5，无可用 openid）：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "payment_no": "ZF237681a6-cd0b-4c3d-a47f-2adc9f67614f",
    "pay_type": 1,
    "amount": 11.98,
    "wechat_pay_params": "{\"h5_url\":\"https://wx.tenpay.com/cgi-bin/mmpayweb-bin/checkmweb?...\"}"
  }
}
```

**发起支付响应（货到付款）：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "payment_no": "ZF237681a6-cd0b-4c3d-a47f-2adc9f67614f",
    "pay_type": 3,
    "amount": 5.5
  }
}
```

`wechat_pay_params` / `alipay_pay_params` 为 JSON **字符串**，前端需二次解析；调起参数按支付方式归属字段，现金支付不返回任何调起参数。前端小程序端用 `uni.requestPayment`（`provider: 'wxpay'`）调起 JSAPI，H5 端跳转 `h5_url`，仅在支付真实完成时提示"支付成功"。

**说明：** 仅待支付（status=1）订单可发起支付；对已支付或已终态的订单发起支付返回 `10004 订单当前状态不可支付`，支付服务层亦存在幂等拦截，订单已有支付成功记录时返回 `10006 订单已支付，请勿重复支付`；渠道未开启或配置不完整时返回 `10001 当前支付方式未开启或配置不完整`；支付单查询发生数据库异常（非"记录不存在"）时返回 `10002 支付状态查询失败，请稍后重试` 并拒绝建单，防止故障被当作无支付记录而导致重复支付，底层错误仅记录服务端日志。
