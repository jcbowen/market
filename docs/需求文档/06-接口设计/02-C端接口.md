#### 社区模块

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | /api/v1/communities | 社区列表 / 附近社区（LBS） | 否 |
| PUT | /api/v1/user/community | 切换社区 | 是 |

> 说明：社区列表接口同时支持附近社区排序。当请求携带 `longitude` 和 `latitude` 参数时，后端按距离由近到远返回社区；否则返回普通社区列表。

**附近社区请求：**
```
GET /api/v1/communities?longitude=113.95&latitude=22.54&page=1&page_size=10
```

**切换社区请求：**
```json
{
  "community_id": 2
}
```
