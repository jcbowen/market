## 六.4 微服务间 gRPC 接口（Protobuf 定义）

### 通用消息定义（common.proto）

```protobuf
syntax = "proto3";

package common;

option go_package = "github.com/jcbowen/market/src/backend/common/proto/common";

// 分页请求
message Pagination {
  int32 page = 1;
  int32 page_size = 2;
}

// 分页响应
message PaginationResponse {
  int32 total = 1;
  int32 page = 2;
  int32 page_size = 3;
}

// 空请求
message Empty {}

// 通用响应
message CommonResponse {
  int32 code = 1;
  string message = 2;
}
```
