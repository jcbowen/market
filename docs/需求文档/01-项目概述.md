## 一、项目概述

### 项目命名

| 项 | 名称 | 说明 |
|---|---|---|
| 中文名 | 玖祺社区商超系统 | 文档、界面展示、对外介绍统一使用 |
| 英文名 | jc_market | 代码仓库、Docker 镜像、二进制名沿用 `market` 短名（如 `jcbowen/market`） |

### 项目简介

玖祺社区商超系统是面向多社区运营的商超商城 + 门店收银台（POS）一体化系统，支持居民在线浏览商品、加入购物车、下单购买（自提 / 配送 / 到店），并配套履约工作台与管理后台。社区维度数据隔离贯穿全部链路。

### 功能全景（现状）

| 模块 | 说明 |
|---|---|
| C 端商城 | 商品浏览/搜索、购物车、下单支付（微信 JSAPI/H5、支付宝、付款码反向扫码）、订单/售后退款、配送地址（严格限定本社区） |
| 门店收银（POS） | 收银台代客下单、付款码收款、交班对账体系 |
| 履约工作台 | 送货上门 + 自提核销，调度器抢单与状态机 |
| 管理后台 | 商品/SKU/库存、营销（划线价、手动优惠）、订单、退款审核、多社区权限体系、行政区划、渠道与支付配置、异步导出与下载中心 |
| 应用中心 | 收银台（直接收款、挂单、交班）、数据导入（演示数据包按条目导入当前社区，仅超管） |
| 实时通知 | 支付成功/退款/导出完成/支付异常/权限变更经 WebSocket 推送后台，含语音播报与系统通知 |
| 多社区架构 | 社区隔离（C 端请求头 X-Community-Id）、管理员多社区任职与实时权限解析、社区级权限上限 |

### 多端覆盖

| 端 | 技术 | 说明 |
|---|---|---|
| 微信小程序 | uni-app 编译 | 原生微信小程序 |
