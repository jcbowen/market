### 2.6 响应式适配方案（H5）

C 端 H5 主要面向手机端设计，在 PC 及平板设备访问时，因屏幕比例差异会导致页面布局变形。为保证非移动设备下的展示效果，采用 **iframe 嵌套 + 手机外观边框容器** 的方案进行适配。

**适配目标：**

- 移动设备访问时保持原生全屏体验，不显示手机边框容器。
- PC 端及平板设备访问时，居中显示模拟手机外观的边框容器。
- 边框容器固定 18:9 比例（375×750 CSS 像素），完整展示内部页面内容。
- 顶部导航栏、底部 tabBar 等 fixed 定位元素在滚动时保持固定，不随页面内容一起移动。

**实现方案：**

- **双模式入口**：
  - Frame 模式（`index.html`）：非移动设备访问 `/s/` 时返回，负责渲染手机边框、缩放及 iframe 容器。
  - App 模式（`app.html`）：iframe 内部加载的真实 H5 应用入口，渲染原生 uni-app 页面，保持全屏体验。
- **iframe 嵌套**：Frame 模式通过 `<iframe>` 加载 App 模式页面，使内部 `uni-page-head`、`uni-tabbar` 等 fixed 定位元素相对于 iframe 自身视口固定，避免外层 `transform` 缩放导致滚动时一起移动。
- **构建后处理**：`build:h5` 构建完成后执行 `src/client/build-frame.js`，将 uni-app 生成的 `index.html` 重命名为 `app.html`，再将 `src/client/frame.html` 复制为新的 `index.html` 并替换 iframe 加载地址。
- **比例与缩放**：手机边框容器宽度固定 375px、高度 750px，通过 CSS 变量 `--device-scale` 按视口大小等比缩放，确保在 PC/平板屏幕内完整显示，缩放比例不超过 1。
- **夜间模式背景**：PC 端外部背景通过 `prefers-color-scheme` 媒体查询自动切换，非夜间模式为 `#f5f5f5`，夜间模式为 `#1a1a1a`。
- **安全响应头**：Gateway 对 `/s/app.html` 设置 `X-Frame-Options: SAMEORIGIN` 及 `frame-ancestors 'self'`，允许同域 iframe 嵌入。

**相关文件：**

- `src/client/frame.html`：Frame 模式页面模板。
- `src/client/build-frame.js`：H5 构建后处理脚本。
- `src/client/src/static/phone-frame.css`：手机边框容器样式，区分 Frame/App 两种模式。
- `src/backend/gateway/middleware/security.go`：设置允许同域 iframe 嵌入的安全头。
