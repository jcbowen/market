### 2.2 微信开发库（wego）

采用自研 [wego](file:///Users/bowen/projects/mine/wego) 库统一管理微信相关开发，模块路径 `github.com/jcbowen/wego`。

#### 已有能力

| 模块 | 功能 | 本项目使用场景 |
|------|------|---------------|
| official_account | 公众号 OAuth 网页授权 | H5 微信服务号登录 |
| official_account | 模板消息 | 订单状态通知 |
| official_account | 客服消息 | 用户咨询回复 |
| official_account | 菜单管理 | 服务号自定义菜单 |
| official_account | 素材管理 | 图片/图文素材 |
| official_account | 订阅消息 | 订单进度通知 |
| official_account | 稳定版 access_token | token 管理 |
| openplatform | 第三方平台授权 | (预留) 多公众号管理 |
| crypto | 消息加解密 | 微信消息安全 |
| storage | 多存储后端（文件/内存/DB/Redis） | token 持久化，本项目使用 DB 存储 |

#### 已补齐能力

wego 库已补齐本项目需要的微信小程序与微信支付能力：

| 模块 | 能力 | 项目使用位置 |
|------|------|-------------|
| `miniprogram` | `Code2Session` 小程序登录 | `gateway/handler/auth.go` |
| `payment` | JSAPI/H5 统一下单 | `services/payment/service/wechat.go` |
| `payment` | 支付回调验签与解密 | `services/payment/service/wechat.go` |
| `payment` | 退款 | `services/payment/service/wechat.go` |
| `payment` | 支付单查询 | wego 已提供，项目按需调用 |

#### 当前实现说明

- `miniprogram/` 与 `payment/` 包已按 wego 架构实现：Config → Client → 统一错误处理。
- 支付证书与密钥当前通过配置文件 `wechat.private_key` 与 `wechat.cert_serial_no` 传入，wego 内部使用文件存储缓存平台证书。
- 后续可考虑将私钥/证书迁移至数据库或安全存储，并通过 `payment.NewClientWithStorage` 注入自定义 `storage.TokenStorage`。
