## 二、技术方案

### 2.1 技术栈

| 层级 | 选型 | 说明 |
|---|---|---|
| 用户端框架 | uni-app 3.x (Vue3) | 一套代码编译多端 |
| 用户端 UI | uView Plus | uni-app 生态组件库 |
| 用户端状态管理 | Pinia | Vue3 官方状态管理 |
| 用户端语言 | TypeScript | 类型安全 |
| 后台管理框架 | Vue3 + Vite | 独立项目 |
| 后台管理 UI | Naive UI | 响应式，移动端友好 |
| 后台管理状态管理 | Pinia | |
| 后台管理语言 | TypeScript | |
| 后端语言 | Go 1.23+ | |
| 后端 Web 框架 | Gin | jcbaseGo 已内置 |
| 后端基础库 | jcbaseGo | 本地路径替换，提供 ORM/Redis/配置/CRUD/中间件/安全/附件/错误码 |
| ORM | GORM | jcbaseGo 已封装 MysqlBaseModel |
| 数据库 | MySQL 8.0 | |
| 缓存 | Redis | jcbaseGo 已封装 Cache |
| 消息队列 | （预留） | 一期使用同步调用，暂不使用 Kafka |
| 注册中心 | （预留） | 服务间通过固定 gRPC 地址调用，暂不使用 Nacos |
| 配置中心 | YAML 文件 | 配置通过本地 YAML 文件管理 |
| RPC | gRPC + Protobuf | 微服务间同步调用 |
| API 网关 | Gin 自建 | 统一入口、鉴权、限流、路由转发 |
| 配置格式 | YAML | 扩展 jcbaseGo 支持 |
| 容器化 | Docker + docker-compose | 一键部署 |
| 数据库迁移 | GORM AutoMigrate | 数据模型自动表迁移，启动时自动建表/增量更新 |
| 微信开发库 | wego | 本地路径替换，封装微信开放平台、公众号、小程序、支付 |
