## 三、目录结构

```
market/                          # 项目根目录，同时作为项目级 GOPATH
├── bin/                         # 运行时目录（所有编译产物 & 配置 & 静态文件）
│   ├── gateway                  # API 网关二进制
│   ├── user-service             # 用户服务二进制
│   ├── product-service          # 商品服务二进制
│   ├── order-service            # 订单服务二进制
│   ├── cart-service             # 购物车服务二进制
│   ├── payment-service          # 支付服务二进制
│   ├── static/                  # 前端静态资源
│   │   ├── h5/                  # 用户端 H5 编译产物
│   │   └── admin/               # 后台管理编译产物
│   ├── config.yaml              # 本地配置文件（YAML）
│   ├── config.docker.yaml       # Docker 配置文件（YAML）
│   └── logs/                    # 运行日志
├── pkg/                         # GOPATH/pkg，go mod tidy 下载的第三方依赖缓存
│   └── mod/                     # Go Modules 缓存目录（已加入 .gitignore，不放项目源码）
├── src/                         # 整个项目的源码
│   ├── client/                  # uni-app 用户端源码
│   ├── admin/                   # 后台管理端源码（Vue3 + Naive UI）
│   └── backend/                 # Go 后端源码
│       ├── go.mod               # Go 模块定义（模块路径：github.com/jcbowen/market/src/backend）
│       ├── go.sum               # 依赖校验文件
│       ├── gateway/             # API 网关
│       ├── services/            # 微服务
│       │   ├── user/
│       │   ├── product/
│       │   ├── order/
│       │   ├── cart/
│       │   └── payment/
│       ├── common/              # 后端公共模块（proto、配置、JWT、错误码、响应封装等）
│       └── deploy/              # Dockerfile
├── deploy/                      # 部署相关文件（init.sql、nginx 配置示例等）
├── docker-compose.yml           # 一键部署
└── docs/                        # 文档
```

**目录约定说明：**

- `bin/` 是唯一的运行时目录。Go 后端通过 `go build` 输出二进制到此，前端 H5 / 管理后台构建后输出到 `bin/static/`。开发期间启动后端时，以 `bin/` 为工作目录运行；Docker 镜像中 `/app` 目录的内容也来自 `bin/`。
- `pkg/` 仅用于存放 `go mod tidy` 自动下载的第三方依赖缓存（`pkg/mod/`），**不得存放项目自身源码**，且已加入 `.gitignore` 进行过滤。
- `src/backend/common/` 存放后端所有公共包，包括 Protobuf 定义、配置读取、JWT、错误码、响应封装等。
- `src/backend/go.mod` 中的模块路径为 `github.com/jcbowen/market/src/backend`，因此 `src/backend/common/proto/user` 的 import 路径为 `github.com/jcbowen/market/src/backend/common/proto/user`。
- Docker 镜像构建时，构建上下文只保留 `bin/` 与 `src/backend/deploy/`（Dockerfile），其余目录均通过 `.dockerignore` 过滤。
