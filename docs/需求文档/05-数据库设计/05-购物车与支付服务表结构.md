#### 5.2.5 payment-service（支付服务）

**payments - 支付记录表**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | 是 | 主键 |
| payment_no | VARCHAR(50) | 是 | 支付单号，使用 UUID 生成 |
| order_id | BIGINT UNSIGNED | 是 | 订单 ID |
| user_id | BIGINT UNSIGNED | 是 | 用户 ID |
| pay_type | TINYINT | 是 | 1微信支付 2支付宝支付 3现金 |
| amount | DECIMAL(10,2) | 是 | 支付金额 |
| status | TINYINT | 是 | 1待支付 2支付成功 3支付失败 4已退款 |
| transaction_id | VARCHAR(100) | 否 | 第三方交易号 |
| pay_params | TEXT | 否 | 第三方支付调起参数 JSON |
| pay_time | DATETIME | 否 | 支付时间 |
| created_at | DATETIME | 是 | |
| updated_at | DATETIME | 是 | |

索引：`uk_payment_no(payment_no)`、`idx_order_id(order_id)`、`idx_user_id(user_id)`

**refund_payments - 退款记录表**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | 是 | 主键 |
| refund_no | VARCHAR(50) | 是 | 退款单号，唯一索引保证幂等 |
| payment_no | VARCHAR(50) | 是 | 关联支付单号 |
| order_id | BIGINT UNSIGNED | 是 | 订单 ID |
| amount | DECIMAL(10,2) | 是 | 退款金额 |
| status | TINYINT | 是 | 1待退款 2退款成功 3退款失败 |
| transaction_id | VARCHAR(100) | 否 | 第三方退款交易号 |
| refund_time | DATETIME | 否 | 退款成功时间 |
| created_at | DATETIME | 是 | |
| updated_at | DATETIME | 是 | |

索引：`uk_refund_no(refund_no)`、`idx_payment_no(payment_no)`、`idx_order_id(order_id)`
