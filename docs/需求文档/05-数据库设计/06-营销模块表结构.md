**coupon_product_scopes - 优惠券商品范围表**

语义：空表（无范围行）= 全部商品可用；存在 scope_type=2/3（包含）行时仅指定分类/商品计入门槛与优惠基数；scope_type=4/5（排除）行命中的商品不计入门槛与优惠基数。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | 是 | 主键 |
| coupon_id | BIGINT UNSIGNED | 是 | 优惠券 ID |
| scope_type | TINYINT | 是 | 1=全部（不落行） 2=包含分类 3=包含商品 4=排除分类 5=排除商品 |
| category_id | BIGINT UNSIGNED | 是 | 分类 ID，scope_type=2/4 时有效，默认 0 |
| product_id | BIGINT UNSIGNED | 是 | 商品 ID，scope_type=3/5 时有效，默认 0 |
| created_at | DATETIME | 是 | |

索引：`idx_coupon_id(coupon_id)`

**user_coupons - 用户优惠券表**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | 是 | 主键 |
| user_id | BIGINT UNSIGNED | 是 | 用户 ID |
| coupon_id | BIGINT UNSIGNED | 是 | 优惠券 ID |
| name | VARCHAR(100) | 是 | 优惠券名称 |
| type | TINYINT | 是 | 1满减券 2折扣券 |
| threshold | DECIMAL(10,2) | 是 | 使用门槛金额，默认 0 |

| status | TINYINT | 是 | 1未使用 2已使用 3已过期，默认1 |
| order_id | BIGINT UNSIGNED | 否 | 关联订单 ID，默认 0 |
| source | TINYINT | 是 | 来源：1用户自领 2后台手动发放，默认1 |
| operator_id | BIGINT UNSIGNED | 是 | 发放经手人（管理员）ID，自领为 0，默认 0 |

| created_at | DATETIME | 是 | |
| updated_at | DATETIME | 是 | |

索引：`idx_user_id(user_id)`、`idx_coupon_id(coupon_id)`

过期流转：product 服务内置 coupon-scheduler（Redis 分布式锁，每分钟一跳）将 `status=1 且 expire_at < NOW()` 的行批量置为 3 已过期（幂等条件更新）。查询侧双保险：未使用筛选（C 端我的券 / 下单 applyCoupon / 后台发放记录 status=1）同步排除已过期未流转的行；使用时 UseCoupon 仍校验 expire_at 兜底。
