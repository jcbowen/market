
#### 5.2.1 user-service（用户服务）

**users - 用户表**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | 是 | 主键 |
| openid | VARCHAR(64) | 否 | 微信 openid |
| alipay_user_id | VARCHAR(64) | 否 | 支付宝 user_id |
| union_id | VARCHAR(64) | 否 | 微信 unionid（多端统一） |
| phone | VARCHAR(20) | 否 | 手机号 |
| nickname | VARCHAR(64) | 否 | 昵称 |
| avatar | VARCHAR(512) | 否 | 头像 URL |
| gender | TINYINT | 是 | 0未知 1男 2女，默认0 |
| community_id | BIGINT UNSIGNED | 否 | 当前选择的社区 ID |
| status | TINYINT | 是 | 1正常 0禁用，默认1 |
| last_login_at | DATETIME | 否 | 最后登录时间 |
| created_at | DATETIME | 是 | |
| updated_at | DATETIME | 是 | |
| deleted_at | DATETIME | 否 | 软删除 |

索引：`uni_users_openid(openid)`、`uni_users_alipay_user_id(alipay_user_id)`、`uni_users_union_id(union_id)`、`uni_users_phone(phone)`、`idx_users_community_id(community_id)`
