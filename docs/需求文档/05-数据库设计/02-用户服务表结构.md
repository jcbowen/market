
#### 5.2.1 user-service（用户服务）

**users - 用户表**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | 是 | 主键 |
| openid | VARCHAR(64) | 否 | 微信 openid |
| alipay_user_id | VARCHAR(64) | 否 | 支付宝 user_id |
| union_id | VARCHAR(64) | 否 | 微信 unionid（多端统一） |
| phone | VARCHAR(20) | 否 | 手机号 |
| nickname | VARCHAR(64) | 否 | 昵称 |
| avatar | VARCHAR(512) | 否 | 头像 URL |
| gender | TINYINT | 是 | 0未知 1男 2女，默认0 |
| community_id | BIGINT UNSIGNED | 否 | 当前选择的社区 ID |
| status | TINYINT | 是 | 1正常 0禁用，默认1 |
| last_login_at | DATETIME | 否 | 最后登录时间 |
| created_at | DATETIME | 是 | |
| updated_at | DATETIME | 是 | |
| deleted_at | DATETIME | 否 | 软删除 |

索引：`uni_users_openid(openid)`、`uni_users_alipay_user_id(alipay_user_id)`、`uni_users_union_id(union_id)`、`uni_users_phone(phone)`、`idx_users_community_id(community_id)`

**user_addresses - 用户地址表**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | 是 | 主键 |
| user_id | BIGINT UNSIGNED | 是 | 用户 ID |
| contact_name | VARCHAR(32) | 是 | 联系人 |
| contact_phone | VARCHAR(20) | 是 | 联系电话 |
| province | VARCHAR(32) | 是 | 省 |
| city | VARCHAR(32) | 是 | 市 |
| district | VARCHAR(32) | 是 | 区 |
| detail | VARCHAR(255) | 是 | 详细地址 |
| tag | VARCHAR(32) | 否 | 标签（家/公司/学校） |
| is_default | TINYINT | 是 | 是否默认地址，默认0 |
| created_at | DATETIME | 是 | |
| updated_at | DATETIME | 是 | |
| deleted_at | DATETIME | 否 | |

索引：`idx_user_id(user_id)`

**communities - 社区表**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | 是 | 主键 |
| name | VARCHAR(128) | 是 | 社区名称 |
| address | VARCHAR(255) | 是 | 地址 |
| longitude | DECIMAL(10,7) | 否 | 经度 |
| latitude | DECIMAL(10,7) | 否 | 纬度 |
| contact_phone | VARCHAR(20) | 否 | 联系电话 |
| pickup_address | VARCHAR(255) | 否 | 自提点地址 |
| delivery_fee | DECIMAL(10,2) | 是 | 配送费，默认0 |
| min_order_amount | DECIMAL(10,2) | 是 | 起送金额，默认0 |
| delivery_range_km | DECIMAL(5,2) | 否 | 配送范围（公里） |
| status | TINYINT | 是 | 1营业 0停业，默认1 |
| business_hours | VARCHAR(128) | 否 | 营业时间描述 |
| sort | INT | 是 | 排序，默认0 |
| created_at | DATETIME | 是 | |
| updated_at | DATETIME | 是 | |
| deleted_at | DATETIME | 否 | |

索引：`idx_status_sort(status, sort)`

**admin_users - 管理员表**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | 是 | 主键 |
| username | VARCHAR(64) | 是 | 用户名 |
| password | VARCHAR(256) | 是 | bcrypt 加密 |
| real_name | VARCHAR(64) | 否 | 真实姓名 |
| phone | VARCHAR(20) | 否 | 手机号 |
| role_id | BIGINT UNSIGNED | 是 | 角色 ID |
| community_id | BIGINT UNSIGNED | 否 | 所属社区（超级管理员为 NULL） |
| status | TINYINT | 是 | 1正常 0禁用，默认1 |
| last_login_at | DATETIME | 否 | 最后登录时间 |
| last_login_ip | VARCHAR(45) | 否 | 最后登录 IP |
| created_at | DATETIME | 是 | |
| updated_at | DATETIME | 是 | |
| deleted_at | DATETIME | 否 | |

索引：`uni_admin_users_username(username)`、`idx_admin_users_role_id(role_id)`、`idx_admin_users_community_id(community_id)`

**admin_roles - 角色表**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | 是 | 主键 |
| name | VARCHAR(64) | 是 | 角色名称 |
| code | VARCHAR(64) | 是 | 角色编码（super_admin / community_admin / staff） |
| permissions | TEXT | 否 | 权限 JSON 数组 |
| description | VARCHAR(255) | 否 | 描述 |
| created_at | DATETIME | 是 | |
| updated_at | DATETIME | 是 | |

索引：`uni_admin_roles_code(code)`
