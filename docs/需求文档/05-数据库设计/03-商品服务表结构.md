**attachment - 附件记录表**

后台图片上传记录（本地上传与 OSS 直传共用）。参考 iMe mat_file 口径：presign 阶段 md5 置空延迟写入，confirm 成功后补写，保证「md5 非空 ⇒ 对象已上传」的不变量，未完成记录天然从秒传查询中隔离。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| admin_id | BIGINT | 上传管理员 ID，0 表示系统上传 |
| type | VARCHAR(64) | 文件 MIME 类型，如 image/png |
| url | VARCHAR(2048) | 完整访问 URL；OSS 为 bucket/自定义域名 + path，本地为空（响应时按请求域名拼接） |
| path | VARCHAR(512) | 对象相对路径：OSS 为对象 Key，本地为附件目录下相对路径 |
| name | VARCHAR(255) | 原始文件名 |
| size | BIGINT | 文件大小（字节） |
| md5 | VARCHAR(32) | 文件 MD5（32 位小写十六进制），秒传查询字段 |
| width | INT | 图片宽度（像素） |
| height | INT | 图片高度（像素） |
| created_at | DATETIME | |
| updated_at | DATETIME | |

索引：`idx_attachment_md5(md5)`

本地模式对象路径规则：`images/{Ymd}/{dd}/mkt{HHmmss}{6位随机}.{ext}`，落盘 `<部署目录>/attachment/` 下，经网关 `/uploads/` 静态路径访问。
