### 7.4 YAML 配置模板

配置文件为 `bin/config.yaml`（本地/非 Docker 运行）、`bin/config.docker.yaml`（多容器 compose 部署）与 `bin/config.allinone.yaml`（一体化镜像内置模板，构建时拷为镜像内 `/app/config.yaml`），结构定义见 `src/backend/common/config/config.go`，加载入口 `internal/bootstrap`。一体化镜像部署的运行期配置修改不走模板挂载，统一编辑宿主机 `./data/runtime/config.yaml` 源配置（entrypoint 首启从内置模板生成，见部署文档 9.3.4a）。

**key 命名注意**：`web_server`、`db`、`redis` 三段由 jcbaseGo 结构体解析，字段没有 yaml tag，按"字段名全小写"匹配，必须写成 `enablessl`、`drivername`、`parsetime`、`singulartable` 等全小写形式（`port`、`db` 为字符串值）；`jwt`、`log`、`grpc`、`geoip` 及末尾各服务 `*_service` 段在项目自身结构体上声明了 yaml tag，正常使用下划线。

**敏感凭据一律不入库**：MySQL/Redis 密码与 JWT 密钥由环境变量 `MYSQL_PASSWORD` / `REDIS_PASSWORD` / `JWT_SECRET` 在启动时覆盖配置文件空占位（`common/config/env.go` 的 `ApplyEnvOverrides`），Docker 部署经根目录 `.env` 注入。

以下为模板（值以实际 `bin/config.yaml` 结构为准，密钥/口令均为占位符）：

```yaml
# ========== HTTP 网关（jcbaseGo.WebServer，key 全小写）==========
web_server:
    port: 18080
    enablessl: false
    certpath: ""
    keypath: ""

# ========== MySQL（jcbaseGo.DbStruct，key 全小写）==========
db:
    drivername: mysql
    protocol: tcp
    host: localhost              # Docker（config.docker.yaml）为 mysql / 外部实例地址
    port: "3306"                 # 字符串
    dbname: market
    username: root
    password: ""                 # 占位：由 MYSQL_PASSWORD 环境变量注入，勿写真实口令
    charset: utf8mb4
    tableprefix: ""
    parsetime: "False"           # config.docker.yaml 为 "True"
    loc: Local
    singulartable: true
    disableforeignkeyconstraintwhenmigrating: false   # config.docker.yaml 为 true

# ========== Redis（jcbaseGo.RedisStruct，key 全小写）==========
redis:
    host: localhost              # Docker 为 redis / 外部实例地址
    port: "6379"                 # 字符串
    password: ""                 # 占位：由 REDIS_PASSWORD 环境变量注入
    db: "0"                      # 字符串

# ========== 项目信息 ==========
project:
    name: 社区商超

# ========== gRPC 服务地址（gateway 等调用方使用的 target）==========

    user_service: localhost:50051      # Docker 为 user-service:50051（容器名），下同
    product_service: localhost:50052
    order_service: localhost:50053
    cart_service: localhost:50054
    payment_service: localhost:50055

# ========== JWT 认证 ==========
jwt:
    secret: "<随机强密钥>"              # 由 JWT_SECRET 环境变量注入；入库默认占位值
                                       # market-secret-key-change-in-production 在 APP_ENV=production
                                       # 时触发 fail-fast 拒绝启动（EnsureSecureJWT）
    access_token_ttl: 7200       # 2小时，秒
    refresh_token_ttl: 604800    # 7天，秒

# ========== 日志 ==========
# 说明：本段会被解析进配置结构，但当前后端代码使用 Go 标准库 log 输出进程标准输出，
# 未接入 zap/文件切割，此段为预留（见 7.8 日志规范）。

    level: info                  # debug | info | warn | error
    format: json                 # json | console
    file_path: logs/
    max_size: 100                # MB
    max_backups: 30
    max_age: 7                   # 天
    compress: true

# ========== 文件上传 ==========
# 注意：附件存储配置已迁移至数据库 attachment_config 表（单行），
# 通过后台「系统管理 → 附件配置」页面维护（存储模式：本地 / 阿里云 OSS，预留 COS），
# 保存后即时生效，无需重启。此 yaml 节仅作为历史遗留保留，运行时不读取：
upload:
    max_size: 10485760           # 10MB
    allowed_types:
        - jpg
        - jpeg
        - png
        - gif
        - webp
    storage: local               # local | oss
    local_path: static/uploads/

# 附件上传接口（gateway admin 分组，权限 settings:view / settings:update）：
#   GET  /api/v1/admin/settings/attachment   # 读取附件配置（Secret 脱敏）
#   PUT  /api/v1/admin/settings/attachment   # 保存附件配置（掩码值不覆盖）
#   POST /api/v1/admin/upload/image          # 本地模式 multipart 上传
#   POST /api/v1/admin/attachment/presign    # OSS 模式预签名（MD5 秒传，命中直接返回 final_url）
#   POST /api/v1/admin/attachment/confirm    # OSS 直传完成后确认（延迟补写 md5）
# 附件记录存于 attachment 表，本地模式文件落盘 <部署目录>/attachment/，经 /uploads/ 静态路径访问。

# ========== IP 定位 ==========
geoip:
    db_path: data/geoip/GeoLite2-City.mmdb   # 相对可执行文件目录；文件由根目录
                                             # download-geoip.mjs 下载更新，不入 git，
                                             # 缺失时定位接口优雅降级

# ========== 微信小程序登录 ==========
# 注意：微信支付/支付宝支付/支付渠道开关等支付配置已迁移至数据库 pay_config 表，
# 通过后台「系统管理 → 支付配置」页面维护（支持上传证书文件、生成回调 URL 引导），保存后即时生效，无需重启。
# 此处仅保留微信小程序登录所需字段（app_id/app_secret）；mch_id 等支付字段虽在结构体中
# （WechatConfig 兼作支付配置的数据载体），实际值取自 pay_config 表，不要写入本文件：
wechat:
    app_id: ""                   # 小程序/公众号 AppID
    app_secret: ""               # 小程序/公众号 AppSecret
    mch_id: ""                   # 以下支付字段仅作载体，运行时以 pay_config 为准
    api_v3_key: ""
    cert_serial_no: ""
    private_key: ""
    notify_url: ""

# ========== 短信服务（预留） ==========
# 说明：sms 为预留配置段，当前代码未实现短信发送（发送验证码接口为空实现，
# 手机号登录暂不校验验证码）；配置结构先行定义，接入服务商时无需变更配置格式。
sms:
    provider: aliyun             # aliyun | tencent
    access_key: ""
    secret_key: ""
    sign_name: 社区商超
    template_code: ""
    code_expire: 300             # 验证码有效期，秒
    send_interval: 60            # 发送间隔，秒

# ========== 业务配置 ==========
business:
    expire_warning_days: 3       # 保质期临期预警提前天数
    order_timeout: 1800          # 订单超时取消，秒（30分钟）
    auto_complete_days: 7        # 自动完成天数（发货后N天自动完成）

# ========== 各微服务 gRPC 监听端口 ==========

    grpc_port: 50051

    grpc_port: 50052

    grpc_port: 50053

    grpc_port: 50054
```
