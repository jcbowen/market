### 7.10 IP 定位服务

C 端「附近社区」在网页定位失败时的 IP 定位兜底，采用**服务端本地数据库**方案，不依赖任何第三方在线定位接口。

#### 方案设计

| 项 | 说明 |
|---|---|
| 数据库 | MaxMind GeoLite2-City（mmdb 格式，城市级精度） |
| 数据来源 | <https://geo.wp-statistics.com/#databases>（jsDelivr CDN 直链，无需注册与鉴权，每周二/五更新） |
| 运行位置 | 仅网关（gateway）加载，纯本地内存查询，无外网请求 |
| 数据库文件 | `bin/data/geoip/GeoLite2-City.mmdb`（相对路径以网关可执行文件所在目录为基准，可经 `geoip.db_path` 配置覆盖） |
| 版本管理 | 数据库文件**不提交 git 仓库**（.gitignore 已忽略 `*.mmdb` / `*.mmdb.gz`），由工具按需下载更新 |
| 更新方式 | `geoip-download` 下载工具（源码 `src/backend/cmd/geoip-download/`，随构建产出各平台二进制）定期执行；网关按文件 mtime **热重载**，替换数据库无需重启 |
| 降级策略 | 数据库文件缺失、内网/回环 IP 或查询未命中时，接口返回 `data: null`，前端提示手动搜索社区，不影响其他功能 |

#### 下载与定期更新

```bash
# 手动下载/更新（数据库 3 天内已更新则跳过；默认 dest 相对当前工作目录解析）
cd src/backend && go run ./cmd/geoip-download --dest ../../bin/data/geoip/GeoLite2-City.mmdb

# 强制重新下载
cd src/backend && go run ./cmd/geoip-download --force --dest ../../bin/data/geoip/GeoLite2-City.mmdb

# 发布包 / 构建产物内直接执行（无任何运行时依赖，服务器无需装 Node）
./bin/linux-amd64/geoip-download
```

启动/构建入口（start-all / build-select / deploy）检测到 `bin/data/geoip/` 缺失 mmdb 时会自动以 `go run` 调用下载器补齐。

生产环境配合 crontab 定期更新（工具自带新鲜度判断，重复执行安全）：

```bash
0 4 * * * cd /opt/market && ./bin/linux-amd64/geoip-download >> logs/geoip-download.log 2>&1
```

Docker 部署时 docker-compose.yml 已将宿主机 `./bin/data/geoip` 挂载到网关容器 `/app/data/geoip`（可写），宿主机或容器内更新文件后网关实时热加载。allinone 单容器模式下 entrypoint 检测 `/app/data/geoip` 无 mmdb 时自动执行容器内置的 `./geoip-download` 下载（失败仅 IP 定位降级，不阻断启动）。

#### 接口说明

```
GET /api/v1/geoip/locate（公开接口，无需登录）
```

按客户端出口 IP（网关按 X-Forwarded-For 等标准头解析真实 IP）返回数据库所能提供的全部定位信息（城市级精度，含经纬度与行政区划）：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "longitude": 114.0579,
    "latitude": 22.5431,
    "accuracy_radius": 100,
    "country": "CN",
    "country_name": "中国",
    "province": "广东",
    "city": "深圳",
    "district": null,
    "postal_code": null,
    "timezone": "Asia/Shanghai"
  }
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| longitude / latitude | 近似经纬度（城市级） |
| accuracy_radius | 定位精度半径（公里），坐标 67% 置信落在该圆内；无数据为 null |
| country / country_name | ISO 国家码与名称（中文优先，英文兜底） |
| province | 一级行政区（省/州），无数据为 null |
| city | 城市，无数据为 null |
| district | 二级行政区（中国部分记录为市辖区），多数为 null |
| postal_code | 邮编（部分国家才有，中国多为 null） |
| timezone | IANA 时区，如 Asia/Shanghai |

未命中时 `data` 为 `null`。当前唯一使用方为 C 端社区选择页（`pages/community/select`）的定位兜底。
