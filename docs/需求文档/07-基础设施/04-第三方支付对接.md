
#### 微信支付

- 使用 wego 库 `payment/` 包
- 支付方式：JSAPI（微信小程序）、H5 支付（微信服务号）
- 支付流程：
  1. 前端调用 `POST /api/v1/payments` 传入 `order_id` 和 `pay_type=1`
  2. 后端校验微信支付 V3 配置完整性，不完整时直接返回错误
  3. 创建独立支付单（`payment_no` 使用 UUID），通过 wego 调用微信统一下单接口
  4. 返回支付参数给前端，前端调起微信支付
  5. 用户支付完成后，微信回调 `POST /api/v1/payments/callback/wechat`
  6. 后端通过 wego 验签解密，仅处理 `TRANSACTION.SUCCESS` 通知，更新支付单和订单状态
- 幂等性：
  - 支付回调通过 `payment_no` 保证幂等处理
  - 退款通过 `refund_no` 唯一索引保证幂等，重复提交直接返回成功
- 多次支付：一笔订单支持生成多笔支付单，`GetPayment` 返回最近一次支付成功记录
- 多次退款：一笔支付单支持多笔部分退款，累计退款金额不超过支付单金额；支付单累计退完时才标记为"已退款"
- 配置展示：当 `wechat` 支付 V3 配置不完整时，C 端不展示微信支付选项

#### 支付宝支付

- 当前保持关闭状态，不在 `payment.enabled_channels` 中启用
- 保留模拟实现，配置仅保存；如需启用需接入支付宝官方 SDK
- 支付流程：与微信支付类似，回调地址为 `/api/v1/payments/callback/alipay`
- 验签：使用支付宝公钥验证回调签名

#### 现金支付

- 线下收款/货到付款，创建支付单时直接标记为支付成功并同步订单状态
- 不经过第三方支付网关
- 退款时仅记录退款流水，不调用第三方接口
